# クリエイティブ進行表

イベント制作の案件と「やること」を、カレンダーと日ごとのリストで管理する1ファイルのWebアプリです。

## できること

- 案件を追加すると、本番日・期間のある作業・締切・打合せ・現場作業がカレンダーに入る
- 日ごとのやることリスト。チェックで完了にでき、遅れているものは先頭にまとめて出る
- 2週間以内の締切の一覧
- 案件ごとの色分けと進み具合の表示
- 日付・内容・種類はあとから手で修正できる

## 使い方

`index.html` をブラウザで開くだけです。インストールやビルドはいりません。

1. 上の欄に案件名を入れて「追加」
2. 本番日、会場、やること（日付・終了日・内容・種類）を入れて保存
3. カレンダーの日付を押すと、その日から先のやることが下に並ぶ

はじめて開いたときは「サンプルを入れて試す」で見本の案件を入れられます。

## 動かす場所による違い

| | claude.ai 上（アーティファクト） | GitHub Pages / PCで直接開く |
|---|---|---|
| データの保存先 | 共有の保存先（どの端末でも同じ内容） | そのブラウザの中だけ |
| スケジュール添付の自動読み取り（画像・PDF・Excel・CSV） | 使える | 使えない（手入力） |
| オフライン版の保存と変更の取り込み | 使える | 不要（ファイル自体がオフラインで動く） |

GitHub Pages や手元で開いた場合、データはそのブラウザの localStorage に保存されます。ブラウザの閲覧データを消すと消えるので注意してください。

## GitHub Pages で公開する

1. リポジトリの Settings → Pages を開く
2. Source を「Deploy from a branch」、Branch を `main` / `/ (root)` にして Save
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けるようになる

## 構成

- `index.html` に HTML・CSS・JavaScript をすべて含む
- 外部から読み込むもの
  - Google Fonts（読み込めないときは端末のフォントで表示）
  - SheetJS と pdf.js（cdnjs）… claude.ai 上で添付を読み取るときだけ使用
